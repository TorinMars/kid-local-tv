📺 Kid Local TV

Each folder is a series, and its files play in name order (Episode 1, Episode 2, …).

Network folders streams · uses no TV storage

Add a shared folder from a NAS, Windows PC or Mac — e.g. smb://nas/Videos/Ocean Friends or \\nas\Videos\Ocean Friends. Videos play straight from the share; nothing is copied to the TV. Sub-folders become series, and new files show up automatically.

Share needs a login?

Leave empty for guest / public shares. The TV keeps the login (in its private app storage) so it can play the videos later.
